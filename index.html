CASE STUDY 01

WhatsApp AI Customer Service + RAG

n8n export: Business Knowledge - Supabase RAG Ingestion
Business view

A customer messages a WhatsApp number with a question. The system waits briefly in case they send a few messages in a row (people often type in bursts), then reads all of them together, looks up the real answer in a private knowledge base of verified business facts, and replies — using only information that's actually true for that business, never a guess.

Technical view

An Evolution API webhook feeds inbound WhatsApp events into n8n. A Postgres function atomically buffers and batches messages per phone number. Once a batch is claimed, a LangChain AI Agent (Groq-backed) answers using a Supabase pgvector store exposed to it as a retrieval tool, and the reply is sent back through the Evolution API. A separate ingestion pipeline (Gemini embeddings + recursive text splitting) populates that vector store.
